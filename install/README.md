# WebHunt 2.2.5

## Установка

Откройте папку **Setup** и запустите **WebHunt__Setup.exe** и следуйте шагам мастера. Установщик содержит готовую версию WebHunt и устанавливает её для текущего пользователя. Он создаёт ярлыки в меню «Пуск» и, по выбору, на рабочем столе.

## Рабочая структура

- `Setup/WebHunt__Setup.exe` — единственный готовый файл для установки.
- `src/` — исходный код приложения.
- `installer_source/` — исходный код мастера установки.
- `assets/` — логотипы и шрифт.
- `build_support/` — описание сборки и требования для неё.
- `tests/` — проверки и небольшие примеры аудитов.

Временные сборки, копии установщика, архивы и разработческие EXE после сборки автоматически удаляются. Пользователь устанавливает программу только через мастер; BAT-файл не нужен.

## Пересборка

Для разработчика: запустите PowerShell-сценарий `build_support/Build-WebHunt.ps1`. Он соберёт новый установщик и заменит `Setup/WebHunt__Setup.exe`. При первом запуске создаётся локальное `.venv`; для загрузки зависимостей нужен интернет.

## Данные программы

Настройки, журналы и база истории аудитов сохраняются в `%LOCALAPPDATA%\WebHunt`.

## Доменная история

Программа сверяет доступные публичные источники и показывает статус каждого. Отсутствие найденных предупреждений не означает подтверждённую безопасность домена; реестры могут скрывать прежних владельцев, а архивы — быть недоступны.
